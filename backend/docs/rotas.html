Hemobridge API

Agendamento de doação de sangue em hemocentros · NestJS + PostgreSQL. Todas as rotas ficam sob o prefixo /api. Referências (RFxx, RNFxx) seguem docs/requisitos.md.

Autenticação

Todas as rotas exigem o cabeçalho Authorization: Bearer <accessToken>, exceto as marcadas como Público. O token é obtido em POST /api/auth/login e vale por 1 hora (JWT_EXPIRACAO). A cada requisição o usuário é relido do banco: conta desativada, hemocentro desativado, troca de senha ou logout invalidam o token na hora.

O hemocentro de quem é da equipe vem sempre do vínculo no banco (/api/auth/me devolve papel e hemocentro), nunca do corpo da requisição (RNF04).

Primeiro acesso (senha provisória)

  1. Contas da equipe e de administradores recebem por e-mail uma senha provisória válida por 72h (RN15).
  2. POST /api/auth/login com a provisória responde "primeiroAcesso": true.
  3. Enquanto isso, só funcionam /auth/me, /auth/logout e /auth/primeiro-acesso*; as demais respondem 403.
  4. POST /api/auth/primeiro-acesso define a senha e devolve um novo token — o anterior deixa de valer.

Histórico compartilhado (RF12)

Cada doação fica vinculada ao hemocentro que a registrou e só ele a escreve. A equipe de outro hemocentro lê o histórico do paciente apenas se ele tiver (ou já teve) agendamento lá; não há busca livre. Toda leitura do histórico é gravada na tabela auditoria.

Formato de erro

{
  "statusCode": 400,
  "error": "Bad Request",
  "message": ["CPF inválido", "E-mail inválido"]   // texto ou lista
}

Códigos usados: 400 dados inválidos ou regra violada · 401 sem token / sessão inválida · 403 perfil ou papel sem permissão, conta ou hemocentro desativado, primeiro acesso pendente · 404 não encontrado (inclui recurso de outro hemocentro) · 409 conflito (CPF, e-mail, CNPJ, horário esgotado, agendamento duplicado) · 423 conta bloqueada por tentativas · 429 limite de requisições (ver cabeçalho Retry-After).

Convenções

  • Campos extras no corpo são recusados (property X should not exist).
  • CPF, CNPJ, CEP e telefone aceitam máscara; são gravados só com dígitos. E-mail é gravado em minúsculas.
  • Senha: 8 a 128 caracteres, com letra maiúscula, letra minúscula e número (RN06).
  • Instantes em ISO 8601 (UTC). Datas em AAAA-MM-DD e horas em HH:mm, no fuso de Brasília.
  • Listas paginadas devolvem { itens, total, pagina, tamanhoPagina }.
  • Na query string, + deve ser enviado como %2B (ex.: tipo=O%2B); a API também aceita O+ sem codificação.
  • Limite geral: 100 requisições/min por IP; rotas sensíveis têm limites próprios.
